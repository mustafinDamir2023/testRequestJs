# Internet Speed Test (Node.js)

Консольный скрипт для замера скорости скачивания файла из сети.
Скрипт выполняет 10 последовательных GET-запросов к указанному URL, замеряет время и объём данных каждого запроса, а затем вычисляет средние показатели.

## Требования

- Установленный **Node.js** (версия 14 или выше).
- Скрипт написан на чистом Node.js без использования сторонних библиотек (не требует `npm install`).

## Как запустить

1. Клонируйте репозиторий:
   git clone https://github.com/mustafinDamir2023/testRequestJs.git

2. Запустите скрипт, передав URL в качестве аргумента.  
   **Важно:** URL должен быть прямым (например, ссылка на изображение), чтобы сервер не возвращал HTML-страницу вместо файла.

   node index.js https://example.com/123

   Или для теста с картинкой (использовал на своём примере):

   node index.js https://wallpaperscraft.ru/download/gory_skaly_ozero_180314/2560x1600

## Единицы измерения

В скрипте используются следующие единицы измерения:

- **Время:** секунды (sec).
- **Размер данных:** Мегабайты (МБ). Где 1 МБ = 1024 × 1024 байт.
- **Скорость:** Мегабиты в секунду (**Мбит/с** или **Mbps**).  
  Это стандартная единица измерения скорости интернета (используется провайдерами).  
  _Формула расчёта:_ `(Всего байт × 8) / (1024 × 1024) / (Всего миллисекунд / 1000)`.

## Особенности реализации

- **Последовательность:** Запросы выполняются строго друг за другом (с использованием `async/await`), чтобы избежать искажения результатов из-за ограничения пропускной способности канала при параллельных запросах.
- **Память:** Данные не накапливаются в оперативной памяти целиком (используется потоковое чтение и подсчёт длины чанков через `res.on('data')`). Это позволяет тестировать файлы любого размера без риска переполнения памяти (OOM).
- **Обработка ошибок:** Скрипт корректно обрабатывает таймауты (15 секунд на запрос), ошибки сети и ответы сервера с кодом, отличным от `200 OK`.
